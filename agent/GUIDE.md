# Agent guide has moved

The operating contract for an AI agent working in this repo is **`/AGENTS.md`** at the repository root
(that is the filename agents look for first).

This pointer is kept so older links resolve:

- **`AGENTS.md`** — read order, discovery step, hard invariants, boot-bisect protocol, verification
  contract, report format, platform traps, scope.
- **`agent/manifest.json`** — the same rules, machine-readable.
- **`agent/audit.sh`** — read-only discovery, JSON on stdout.
- **`agent/playbooks/`** — disable-a-unit, remove-an-app, diagnose-broken-feature, reclaim-memory.
